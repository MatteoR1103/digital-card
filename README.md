# Matteo Rubini digital business card

S3C-inspired card published at https://matteor1103.github.io/digital-card/

## Update

Edit `index.html` and `Matteo_Rubini.vcf` together when contact details change.
GitHub Pages publishes the root of the `main` branch. The QR encodes the stable
website URL, so changing contact details does not require replacing the QR.

## Pass2U Wallet

Edit the existing pass in Pass2U Wallet, select QR as its barcode format, and
replace the barcode content with the website URL above. If using image import,
use `Matteo_Rubini_QR.png`. Save and update/add the pass to Apple Wallet. If the
existing pass cannot be edited, create a replacement using the same artwork and
the new URL. Scan with another phone: it should open the page; Save to Contacts
should open/download Matteo_Rubini.vcf for contact import.

Only the public professional card files are included; no credentials are needed.
